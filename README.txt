ТЕХНОМАРКЕТ — версия с корзиной и оформлением заказа

В ZIP находятся index.html, products.json, netlify.toml и Netlify Function для Telegram.

Загрузка: распакуйте архив и перетащите папку проекта в Netlify Deploys.

ВАЖНО: корзина работает в браузере. Для приёма заказов через Telegram нужно, чтобы взрослый владелец магазина создал бота и безопасно добавил в Netlify → Site configuration → Environment variables две переменные:
TELEGRAM_BOT_TOKEN — токен бота (секрет, никому не отправлять и не вставлять в HTML)
TELEGRAM_CHAT_ID — ID чата/группы, куда приходят заказы
После добавления переменных запустите новый Deploy. Не публикуйте токен в открытом виде.

Онлайн-эквайринг ещё не подключён. Сейчас покупатель может выбрать оплату при получении или запросить онлайн-ссылку после подтверждения заказа продавцом. Для автоматической оплаты понадобится отдельная интеграция с платёжным провайдером, оформленная владельцем магазина.

Панель администратора и хранение истории заказов пока не входят в эту версию.


ПОИСК ГОРОДОВ И ОТДЕЛЕНИЙ НОВОЙ ПОЧТЫ
1. Для динамических подсказок требуется Netlify Function и API-ключ Новой почты.
2. В настройках сайта Netlify добавьте переменную окружения NP_API_KEY со своим API-ключом. Не вставляйте ключ в index.html и не отправляйте его в чат.
3. Функции Netlify не публикуются обычной загрузкой папки сайта через drag-and-drop. Разверните этот проект через Git-репозиторий или Netlify CLI, сохранив структуру netlify/functions.
4. Существующие переменные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID для отправки заказов в Telegram оставьте без изменений.
5. После публикации проверьте выбор города, поиск отделения по номеру и по части адреса. Для Укрпочты и самовывоза остаётся ручной ввод.
